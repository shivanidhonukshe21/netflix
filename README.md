# Netflix UI Clone 🎬

A responsive **Netflix homepage UI clone** built using **HTML, CSS, and JavaScript**.  
This project is created for learning purposes to improve front-end development skills and understand UI structuring.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ✨ Features
- Responsive Netflix-style landing page
- Navigation bar with hover effects
- Hero banner section
- Movie categories layout
- Smooth scrolling UI
- Clean and modern design

-

## ⚙️ How to Run the Project
1. Download or clone the repository  
2. Open `index.html` in any browser  
3. Enjoy the UI clone 🎉  


## 🎯 Purpose of Project
This project was built to practice:
- Frontend layout design
- CSS styling and responsiveness
- JavaScript DOM manipulation
- UI cloning of real-world websites
